## 3. Форматы, которые стабильно виралятся (структура, не контент)

1. Reaction/duet — реакция на чужое → в игре: NPC-реакции на рекорды игрока.
2. POV-скиты — узнаваемые ситуации → ситуации в игре должны быть узнаваемы («дедлайн», «хайп прошел»).
3. Before/After — трансформация → визуальный прогресс студии (сарай → небоскрёб).
4. Trend remix — «тот же формат, новый угол» → ремикс мемов игроком (комбинации!).
5. «Неожиданный исход» — скриншот «ПОЧЕМУ ЭТО ПРОИЗОШЛО» → редкие абсурдные ивенты.

## 4. Механическая интеграция мемов (принцип проекта)

Мем — НЕ картинка, а **сущность с жизненным циклом**:

```
FRESH → RISING → VIRAL → PEAK → CRINGE → DEAD (→ NOSTALGIA через сезон)
```

Игрок взаимодействует с циклом: заметить рано → вложиться → продать на пике → не остаться с «кринжем».
Это и есть core loop выбранной концепции. Контент (мемы) — данные в MemeRegistry,
баланс правится без переписывания кода. Устаревшие мемы «умирают» внутри лора игры —
это фича, а не проблема: игра сама про это.

## 5. Оценка свежести (риск устаревания)

- Высокий риск: Punch Monkey, Skibidi, конкретные звуковые мемы → только как minor-ивенты.
- Средний: Italian Brainrot (пик прошёл, но у детей держится), Labubu.
- Низкий (структурные, долгоживущие): сам цикл хайп→кринж, «6-7» как число, Воздухан-архетип,
  Черемша-абсурд, Nihilist Penguin-архетип, коллекционирование, blind-box.
- Стратегия: ядро игры строится на СТРУКТУРНЫХ мемах (цикл трендов), конкретные мемы —
  заменяемый контент через MemeRegistry + сезоны (первый сезон: «Great Meme Reset»).
