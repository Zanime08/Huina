# HYPE FACTORY / «Мемная фабрика» — Game Design Document

## 1. One-sentence pitch
Ты — продюсер мем-студии: замечай тренды раньше всех, вкладывайся в производство,
продавай на пике хайпа и успей слить до того, как мем станет кринжем.

## 2. Core loop (одно предложение)
Заметь растущий мем → вложись (FARM) → подтолкни хайп (BOOST) → продай на пике (SELL) →
переживи новости-ивенты → закончи сезон в плюсе → прокачай студию → новый сезон.

## 3. Фантазия игрока
«Я — серый кардинал интернета. Я знаю, что взлетит завтра». Власть, чутьё, риск, абсурд.

## 4. Сессия: сезон = 10 дней ≈ 4–5 минут
- День длится ~22 секунды, дни тикают автоматически (пауза доступна).
- На экране 3–5 активных мемов (карточки): хайп-бар 0–100, фаза, цена, твой стейк, тренд-стрелка.
- Действия игрока (всё — тапы, mobile-first, portrait):
  - **FARM (+N)**: купить долю за кэш. Поднимает хайп мема чуть-чуть (ты его форсишь).
  - **SELL**: продать долю по текущей цене = f(хайп). Прибыль/убыток мгновенно.
  - **BOOST** (энергия ⚡): сильный толчок хайпа выбранного мема + шанс «завирусить».
  - Новости дня (тикер): 1–2 ивента в день двигают хайп («Воздухан чихнул в эфире +35»).
- Конец сезона: итоговая прибыль vs цель → 1–3 звезды → награды → мета-экран.

## 5. Симуляция мема (сердце игры)
- Скрытые статы: `virality` (скорость роста), `stamina` (долгота жизни), `volatility` (шум).
- Хайп каждый тик: дрейф по жизненной кривой + шум + влияние игрока + ивенты.
- Фазы от хайпа и возраста: FRESH → RISING → VIRAL → PEAK → CRINGE → DEAD.
- Цена = хайп × множитель фазы (на PEAK ×2, на CRINGE ×0.2). Держать мёртвый мем = убыток.
- В пуле сезона ~10 мемов, активны 3–5; мёртвые заменяются новыми (коллекция пополняется).

## 6. Первые 30 секунд (онбординг без чтения)
0–5с: «День 1. У тебя 100 монет. Мем „Воздуханчик" растёт — жми FARM!» (подсветка).
5–15с: хайп растёт, цена растёт, стейк зеленеет → «Жми SELL — зафиксируй прибыль!» → фанфары, +монеты.
15–30с: новость-ивент «Бурмалда проснулась!» → новый мем → «Успей до пика!».
Дальше игрок свободен. Туториал — 3 интерактивные подсказки, скипается автоматически.

## 7. Победа/поражение
- Цель сезона: прибыль ≥ X (растёт по сезонам). Победа: звёзды + монеты + слот коллекции.
- Поражение: «Студия в минусе… но мемы помнят героев» → утешительные монеты, коллекция сохраняется.
- Рестарт в 1 тап. Причина повторить: «я ЗНАЛ, что Бурмалда взлетит, просто рано продал».

## 8. Мета-прогрессия (retention)
- Монеты → прокачка студии (5 веток: стартовый кэш, энергия, удача, слоты мемов, интуиция-инсайды).
- Визуал студии растёт: гараж → офис → небоскрёб «ХАЙП» (before/after для виральности).
- Коллекция мемов (альбом, % собранных, редкости).
- Достижения (12+): «Продал на самом пике», «Пережил 3 краха», «Нишевость» (редкий мем) и т.д.
- Daily Challenge: фиксированный сид дня, отдельный лидерборд.
- Лидерборд: лучший профит сезона (all-time + weekly).
- Сезоны контента: Season 1 «Great Meme Reset» — ротация пула мемов через данные.

## 9. Экономика
- Валюта: монеты (soft). Источники: профит сезонов, дейлики, ачивки, RV.
- Стоки: апгрейды (растущие цены), косметика студии.
- Баланс: сезон даёт 80–300 монет; апгрейд T1 ≈ 150–400; полный T1-сет за ~5–7 сезонов (≈30 мин игры).
- Античит: серверное время Яндекса для дейлика; награды валидируются диапазонами.

## 10. Монетизация (не разрушает игру)
- Rewarded: x2 награды сезона (результаты), «Бейлаут» +кэш в сезоне (1 раз), «Инсайд» (показать завтрашние новости).
- Interstitial: только на экране результатов, не чаще 1 раза в ~3 мин активной игры, с паузой звука/сима.
- Sticky-баннер: НЕ используем (ломает UX менеджера).
- Награда только по колбэку SDK; при недоступности рекламы — graceful fallback (меньшая награда за ожидание? нет — просто скрыть кнопку).

## 11. Виральность («ПОЧЕМУ ЭТО ПРОИЗОШЛО»)
- Абсурдные новости-ивенты («Кот Котость съел серверную: −50% всем»).
- Редкий ивент «БУРМАЛДА» (x10 на случайный мем).
- Кнопка «Поделиться результатом» (скриншот-текст для соцсетей, без SDK-шаринга — копирование текста).
- Графики «как я потерял всё на Черемше».

## 12. Стек и ограничения
- TypeScript + Vite, UI на DOM/CSS (идеально для менеджера + responsive), Canvas только для мини-графиков.
- Звук: синтезированный WebAudio (ноль внешних ассетов, ноль лицензий).
- Графика: оригинальные SVG-аватары мемов (процедурные рожицы), единый стиль «неон-офис».
- Размер: цель < 2 МБ total. Офлайн: Service Worker. Портрет + десктоп-адаптация.

## 13. Локализация
RU + EN с дня 1, все тексты в locales/*.json. Мемы имеют имена на обоих языках.

## 14. Что НЕ входит в релиз (план обновлений)
- Косметические скины студии (сезон 2), PvP-турниры сезонов, кланы, UGC-мемы (модерация!), платежи (in-app).
