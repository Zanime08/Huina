## Известные ограничения (актуально для v1.3)
- Сабмит рекордов клиентский (анти-абьюз: только новый личный рекорд, только доигранные
  сезоны, серверное время для дейлики/недели), но серверной валидации цифр нет —
  Yandex лидерборды для авторизованных это нивелируют
- Офлайн (SW) — только кэш статики; дейлик без сети считает по локальным часам
  (реально недостижимо на платформе: SDK офлайн → все режимы играют, время берётся из Date.now)
- Музыка — один синтезированный луп; SFX — ретро-осцилляторы (осознанный стиль)
- Cloud save conflict — эвристика «больше сезонов/монет выигрывает» (не по-полевое слияние)
- Флаги getFlags — клиентское применение с клампами (не граница доверия, а тюнинг)
- Метрика опциональна (VITE_METRICA_ID); без неё — только in-memory лог + флаги-логи
