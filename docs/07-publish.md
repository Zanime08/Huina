# Публикация на Яндекс Играх

## 1. Сборка
```bash
npm run package        # = build + zip → hype-factory-<version>.zip
```
Проверь: в архиве `index.html` (в корне!), `sw.js`, `assets/*`. Пути относительные (`base: './'`).

## 2. Черновик в консоли
1. https://games.yandex.ru/console → «Добавить игру».
2. Залей ZIP. Название: **HYPE FACTORY — Мемная фабрика** (везде одинаково!).
3. Жанры: Стратегия / Казуальные. Возраст: 6+ (нет насилия, текст без мата).
4. Ориентация: portrait + landscape (responsive). Платформы: desktop + mobile.
5. Языки: Русский, English.

## 3. Монетизация (вкладка «Реклама»)
1. Включи монетизацию (Fullscreen + Rewarded). Sticky-баннер НЕ включай (ломает UX).
2. Проверь в черновике: интерстишл на экране результатов, RV за x2/бейлаут.

## 4. Лидерборды (вкладка «Лидерборды»)
Создай два, имена ТОЧНО такие (используются в коде):
- `hype_season_profit` — «Лучший профит» (порядок: по убыванию)
- `hype_daily_profit` — «Дейлик» (по убыванию)
- `hype_weekly_profit` — «Турнир недели» (по убыванию)

## 5. Промо-материалы
- Иконка 512×512, обложка 800×450: реальный геймплей ≥70% кадра.
- Описание: «Стань продюсером мем-студии! Покупай тренды дёшево, продавай на пике.
  Успей слить мем, пока он не стал кринжем. 10 дней. 12 мемов. Один сезон славы.»
- Сделай 3–5 скриншотов из игры (меню, сезон, пик хайпа, результаты).

## 6. Модерация
- Проверь чеклист `docs/06-qa.md` (раздел «Требования Яндекса»).
- Частые причины отказа и наши митигации:
  - реклама во время геймплея → только экран результатов;
  - игра не запускается → boot работает без SDK;
  - чужой контент → все ассеты оригинальные;
  - обман в промо → скрины только из игры.

## 7. После релиза
- Следи за отзывами первые 2 недели; быстрые фиксы — баланс (всё в `src/config.ts`).
- Сезон 2 контента: добавить мемы в `data/memes.json` + ивенты, поднять `CONFIG.season`.
