## Ручной прогон (preview / draft)
- [ ] Первый запуск: онбординг из 3 подсказок, игра понятна без чтения
- [ ] Повторный запуск: монеты/апгрейды/коллекция на месте
- [ ] SDK недоступен (локально): игра работает на MockPlatform
- [ ] Rewarded: бейлаут, x2 награды; награда только после досмотра
- [ ] Rewarded fail: кнопка разблокируется, тост об ошибке
- [ ] Interstitial: только на результатах, не чаще ~3 мин активной игры
- [ ] Сохранения: localStorage всегда; cloud при доступном player
- [ ] Повреждённый save: дефолты, игра не падает (debug: corrupt save)
- [ ] Маленький телефон (360×640), планшет, десктоп 1920
- [ ] Touch: все кнопки ≥ 40px, нет hover-зависимостей
- [ ] Keyboard: 1–5 farm, Shift+1–5 sell, Space пауза
- [ ] Сворачивание вкладки: автопауза
- [ ] Game Over (проигрыш) → retry в 1 тап
- [ ] Дейлик: 1 раз в день, отдельный рекорд
- [ ] RU/EN: все экраны, новости, имена мемов
- [ ] Звук: музыка/sfx слайдеры, mute; пауза звука во время рекламы
- [ ] Консоль браузера: ноль ошибок
- [ ] FPS на слабом Android: стабильно (DOM-обновления минимальны, rAF один)
