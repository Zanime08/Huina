# HYPE FACTORY — Мемная фабрика

Менеджер мем-трендов для Яндекс Игр. Покупай доли растущих мемов, продавай на пике хайпа,
не держи кринж. Сезон = 10 дней ≈ 4 минуты. Чистый TypeScript + Vite, ноль внешних ассетов.

**Статус: v1.0 — release candidate.** 31/31 теста, 26 мемов в 3 контент-сезонах,
полная интеграция Yandex Games SDK, code review закрыт (docs/09).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 31 тест: sim / economy / balance / helpers / smoke
npm run build    # production в dist/ (~78 КБ JS, 28 КБ gzip)
```

Debug-панель (только dev): `http://localhost:3000/?debug=1`

## Публикация на Яндекс Играх

Кратко: собери `dist/`, залей ZIP в [черновик](https://games.yandex.ru/console),
подключи монетизацию и лидерборды. Полная инструкция: `docs/07-publish.md`.

## Лидерборды (создать в консоли)

- `hype_season_profit` — лучший профит сезона
- `hype_daily_profit` — лучший профит дейлика

Сабмит только при новом личном рекорде, только для доигранных сезонов.

## Что нового в v1.0

- **Сезон 3 «Пуховая лихорадка»**: Пухосос, Плаксик, Дрысясися, Сова на Скакалке,
  Седая Нейро-Ночь, Формула 49, Муся Это Ты, Пёс на Серфе (анлок после 10 сезонов)
- **Честная экономика**: покупка не накачивает цену (закрыт pump-and-dump),
  комиссия платформы 2%, каждый уровень кофемашины полезен
- **Анти-абьюз мета**: выход из дейлики не платит и не сжигает попытку;
  сезоны засчитываются только доигранные; лидерборд — только на рекорд
- **SDK-гигиена**: mute звука на любой рекламе, обработка game_api_pause,
  корректный `isAvailableMethod('leaderboards.setScore')`
- **Тех.**: network-first service worker (обновления доезжают), XSS-экранирование
  ников лидерборда, PAUSED в state machine, спарклайны без перерисовки 60 fps

## Лицензии

Весь код, графика (процедурная SVG), звуки (синтез WebAudio) — оригинальные, созданы для проекта.
Внешних ассетов нет. Meme-имена — пародийные оригиналы; реальные персоны не используются.
